About me

Full Stack Developer passionate about technology

I'm a Systems Engineer and Full Stack Developer certified in JavaScript and Python, with experience in developing complete web applications—from user interface design to database and server implementation. I also have experience building mobile applications using libraries such as Kivy and Tkinter.

My career combines teaching and software development, allowing me to develop a comprehensive perspective on technology as a tool for education, innovation, and digital transformation.

My main tech stack includes React.js and Vue.js for frontend development, Node.js and Django for backend development, and database systems such as MongoDB and MySQL. I also have experience in DevOps with Docker and AWS, as well as data analytics using Excel and Power BI.

I am passionate about continuous learning, data analysis, and creating innovative technological and educational solutions.

Outside of work, I enjoy contributing to open-source projects and sharing knowledge through blogs and educational spaces.
