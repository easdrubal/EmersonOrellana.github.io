# EmersonOrellana.github.io

🌐 Portafolio Personal

Este repositorio contiene mi portafolio personal, desarrollado con HTML, CSS y Tailwind CSS, diseñado para mostrar mis proyectos, habilidades y experiencia profesional de forma clara, moderna y accesible.

El objetivo principal del sitio es servir como herramienta de presentación profesional para oportunidades laborales, destacando tanto el diseño UX/UI como la estructura técnica del proyecto.

🛠️ Tecnologías utilizadas

  * HTML5 – Estructura semántica.
  * CSS3 – Estilos personalizados.
  * Tailwind CSS – Diseño rápido, consistente y escalable.
  * Git & GitHub – Control de versiones y despliegue.
  * GitHub Pages – Hosting del sitio.
